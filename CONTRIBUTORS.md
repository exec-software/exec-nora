## Community contributors

Contributions to the project and package model, directory discovery, build
types, compiler and platform detection, documentation, and examples are
welcome. Open an issue describing the change before reworking a public
`nora_*` contract, because adopting workspaces depend on those names.

When submitting a contribution, you may add your preferred name below, with an
optional profile link and a brief description of your work. Keep this section
in alphabetical order by name.
